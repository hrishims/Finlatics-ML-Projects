# Finlatics Machine Learning Program — Projects

Three applied machine learning case studies completed as part of my **Finlatics Machine Learning Program**, covering regression, clustering, and classification.

| Project | Technique | Folder |
|---|---|---|
| Sales Prediction | Multiple Linear Regression | [`sales-prediction-regression`](./sales-prediction-regression) |
| Facebook Engagement Clustering | K-Means Clustering | [`facebook-engagement-clustering`](./facebook-engagement-clustering) |
| Wine Quality Classification | Decision Tree vs. Random Forest | [`wine-quality-classification`](./wine-quality-classification) |

## Tools & Libraries
Python, Pandas, NumPy, Scikit-learn, Matplotlib
